# NIP Assets

노아이디어피자 / 노아이디어서플라이 랜딩 제작용 에셋 폴더다.

---

## 폴더 구조

### `hero/`

히어로 섹션에 직접 쓰는 배경, 오브젝트, 누끼 이미지.

- `hero-bg-desktop.webp`: 현재 PC 히어로 배경
- `hero-bg-mobile.webp`: 현재 모바일 히어로 배경
- `노아이디어피자-히어로-섹션.webp`: 생성/시안 계열 히어로 후보

### `logo/`

브랜드 로고, 슬로건, 심볼, 일러스트.

히어로에는 크게 쓰지 않고 작은 신뢰 장치나 카드 안에 사용한다.

### `proof/`

브랜드 증거 자료.

- 메뉴 다량 노출 이미지
- 웨이팅/매장 외부 증거
- 지도, 섹션 이미지, 카카오톡 전달 이미지

히어로보다는 `Brand Proof` 섹션에 적합하다.

### `store/`

실제 매장 공간 사진.

코발트블루, 화이트, 밝은 매장 톤을 보여주는 자료다.  
히어로 배경보다는 공간 증거 카드, About 섹션에 적합하다.

### `dough/`

폴리쉬 도우 관련 사진.

제품력, 제조 방식, 도우 기술을 설명하는 섹션에 사용한다.

### `video/`

영상 자료.

용량이 크므로 최종 배포 전 Cloudflare R2 등 외부 스토리지로 옮기고 URL 참조 방식으로 바꾸는 것이 좋다.

### `docs/`

브랜드 로고 플랜, PDF, 참고 문서.

### `menu/`

메뉴별 이미지와 콘셉트 샷.

히어로 오브젝트 후보는 이 폴더에서 피자 단품/누끼에 가까운 이미지를 우선 검토한다.

---

## 현재 판단

히어로는 전체 사진 배경보다 `밝은 배경 + 피자 오브젝트` 방식이 더 적합하다.

우선 후보:

- `proof/brand_origin_2.jpg`: 피자 에너지가 강하지만 그대로 쓰기엔 복잡함. 누끼/오브젝트화 후보.
- `menu/` 내부 메뉴 사진: 단품 피자 오브젝트 후보.
- `store/매장사진*.jpg`: 히어로보다 브랜드 증거 섹션 후보.
- `dough/폴리쉬도우*.jpg`: 히어로보다 도우 기술 섹션 후보.
