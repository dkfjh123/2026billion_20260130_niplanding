# 글로우 카드 섹션 디자인 프롬프트

> 원본 프롬프트를 nip_landing 프로젝트 구조에 맞게 변형.  
> 적용 대상: Pain Bridge 섹션 (프랜차이즈 비용 카드 + 개인창업 질문 카드)

---

## 기술 스택 (프로젝트 기존 스택 유지)

- React 19, Vite, Tailwind CSS v4
- `lucide-react` 아이콘
- `motion/react` 애니메이션

## 섹션 컨테이너

Pain Bridge 전체를 다크 컨테이너로 감싼다.

```
rounded-[32px] bg-[#0A0A0B] px-6 py-12 md:px-12 md:py-16
```

## GlowCard 컴포넌트 구조

재사용 가능한 `GlowCard` 컴포넌트. props: `gradient`, `delay`, `children`.

### 카드 래퍼

```
relative flex flex-col w-full group
```

### 글로우 배경 (핵심)

카드 뒤에 절대 위치로 놓는 블러 레이어:

```html
<div
  className="pointer-events-none absolute inset-0 opacity-50 rounded-[32px]"
  style={{ background: gradient, filter: "blur(45px)" }}
/>
```

### 전면 카드 + 그래디언트 보더 (핵심)

글로우 위에 올리는 실제 카드. `background-clip` 기법으로 테두리에 그래디언트를 적용한다.

```html
<div
  className="relative z-10 overflow-hidden rounded-[32px]"
  style={{
    border: "1.5px solid transparent",
    background: `linear-gradient(#1A1A1C, #1A1A1C) padding-box, ${gradient} border-box`,
  }}
>
  <div className="flex flex-col justify-between p-7">
    {children}
  </div>
</div>
```

### 애니메이션

```tsx
<motion.div
  initial={{ opacity: 0, y: 30 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, margin: "-60px" }}
  transition={{ duration: 0.8, ease: "easeOut", delay }}
>
```

## 프랜차이즈 비용 카드 (3열)

`grid grid-cols-1 sm:grid-cols-3 gap-4`

각 카드에 큰 숫자 + 짧은 설명. 따뜻한 톤 그래디언트 (비용의 무게감).

| 카드 | 숫자 | 설명 | 그래디언트 |
|------|------|------|-----------|
| 가맹비 | 1,000만 원 | 오픈 전에 먼저 나가는 가맹비. | `linear-gradient(137deg, #FF3D77 0%, #FFB1CE 45%, #FF9D3C 100%)` |
| 로열티 | 100만 원 | 매달 빠져나가는 로열티. | `linear-gradient(137deg, #FF6B35 0%, #FFD07B 45%, #FF3D77 100%)` |
| 인테리어 | 8,000만 원 | 본사 기준에 맞추는 인테리어 비용. | `linear-gradient(137deg, #C73E6B 0%, #FF8FA3 45%, #FF6B35 100%)` |

### 카드 내부 레이아웃

```html
<div className="flex h-full min-h-[180px] flex-col justify-end sm:min-h-[220px]">
  <span className="font-rubik text-[32px] font-black text-white sm:text-[38px]">
    {number}
  </span>
  <span className="mt-2 text-[14px] text-gray-400 leading-relaxed">
    {label}
  </span>
</div>
```

## 개인창업 질문 카드 (2x2)

`grid grid-cols-1 sm:grid-cols-2 gap-4`

물음표 형식의 질문. 차가운 톤 그래디언트 (불확실함).

| 카드 | 질문 | 그래디언트 |
|------|------|-----------|
| 1 | 시중에서 쉽게 구하는 치즈와 고기류로, 손님이 다시 올 이유를 만들 수 있을까요? | `linear-gradient(137deg, #4361EE 0%, #7DD3FC 45%, #06B6D4 100%)` |
| 2 | 원팩 구조의 육수와 양념으로, 옆 매장과 다른 맛을 낼 수 있을까요? | `linear-gradient(137deg, #3B82F6 0%, #93C5FD 45%, #4361EE 100%)` |
| 3 | 누구나 쓰는 소스, 누구나 쓰는 원두로 시그니처 메뉴가 만들어질까요? | `linear-gradient(137deg, #6366F1 0%, #A5B4FC 45%, #3B82F6 100%)` |
| 4 | 레시피도, 공급처도, 브랜드 기획도 혼자서 — 어디서부터 시작하시겠습니까? | `linear-gradient(137deg, #4361EE 0%, #E0AEFF 45%, #6366F1 100%)` |

### 카드 내부 레이아웃

```html
<div className="flex h-full min-h-[160px] flex-col justify-end sm:min-h-[180px]">
  <p className="text-[15px] font-medium text-gray-300 leading-relaxed">
    {question}
  </p>
</div>
```

## 헤딩·전환 텍스트

다크 컨테이너 안이므로 텍스트는 화이트 계열.

- 메인 헤딩: `text-white font-bold`
- 서브 텍스트: `text-gray-400`
- 전환 문구: `text-white/80 font-semibold`
