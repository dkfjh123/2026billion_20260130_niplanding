# 노아이디어피자 브랜드 정리

> 목적: 노아이디어서플라이 랜딩을 만들기 전에, 노아이디어피자라는 브랜드의 실체, 강점, 증거 자산, 메뉴 경쟁력, B2B 전환 가능성을 먼저 정리한다.

## 정리 순서

1. `01_브랜드_개요.md`  
   노아이디어피자가 어떤 브랜드인지, 어떤 태도와 감도를 갖는지 정리한다.

2. `02_브랜드_증거자산.md`  
   실제 매장, 고객 반응, 공간, 메뉴 비주얼, 운영 실재감처럼 랜딩에서 신뢰 근거로 쓸 자산을 모은다.

3. `03_메뉴와_상품모듈.md`  
   소비자 메뉴를 그대로 나열하지 않고, B2B 공급 가능한 도우, 소스, 토핑, 사이드, 간편 조리 상품 관점으로 다시 해석한다.

4. `04_B2B_전환_관점.md`  
   노아이디어피자의 브랜드 자산을 파트너 매장의 자기 메뉴로 전환할 때 어떤 메시지로 바꿔야 하는지 정리한다.

5. `05_자료_인벤토리.md`  
   사진, 영상, 레퍼런스, 추후 확보해야 할 자료를 추적한다.

6. `06_폴리쉬도우_레퍼런스.md`  
   노아이디어피자의 제품력 근거가 되는 폴리쉬 도우의 특징과 랜딩 활용 문구를 정리한다.

7. `07_네이버플레이스_메뉴_요약.md`  
   `naverpalce_menu.json`의 실제 메뉴 데이터를 바탕으로 핵심 메뉴, 주문 수, 상품 모듈 전환 포인트를 정리한다.

---

## 핵심 원칙

노아이디어피자는 랜딩의 주인공이지만, 파트너 매장의 간판이 되는 브랜드는 아니다.

이 폴더의 모든 정리는 다음 질문으로 귀결되어야 한다.
